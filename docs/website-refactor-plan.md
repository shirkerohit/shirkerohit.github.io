# Personal website refactor plan

## Goal
Create a minimal, calm personal website for Rohit Shirke that feels thoughtful and professional rather than flashy. The new version should be easy to maintain, easy to extend, and structured for future updates.

## Design direction
- Keep the tone quiet and confident.
- Favor clarity, spacing, and strong typography over visual noise.
- Highlight core work: software engineering, AI systems, practical product thinking, and writing.
- Keep a simple navigation flow: About, Work, Writing, Contact.

## Implementation phases
1. Scaffold a lightweight React app with Vite.
2. Transfer the existing content into a smaller, cleaner information architecture.
3. Build a minimal responsive layout with a simple dark/light mode toggle.
4. Add maintainable content data so future edits are straightforward.
5. Verify the build locally and leave the project in a resumable state.

## Deliverables
- A React-based single-page portfolio site.
- A clean home page with sections for introduction, focus areas, writing, and contact.
- A simple styling system that is easy to adjust later.
- A short README and plan file so another agent can continue from the same starting point.

## Success criteria
- The site builds without errors.
- The UX feels minimal and polished.
- Content is organized around the person’s work rather than decorative effects.
- Future updates can be made by editing a small set of structured content files.
